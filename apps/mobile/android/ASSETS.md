# Android template assets

The generated Android project uses the Capacitor CLI 8.4.3 template. Its legacy launcher and splash PNGs originate from that npm package's Android template and retain its MIT provenance; no generated photographic assets are used.

The Android 8+ adaptive launcher foreground is the repository-native `hermes_monitor_foreground.xml`, drawn to match the monitor symbol in the mobile UI. The color inherits the Hermes Desktop default blue. It is an independent adaptation, not an official Nous Research app icon.
